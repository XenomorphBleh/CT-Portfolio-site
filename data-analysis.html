Data Analysis - personal reflection

For my second project I have learned and applied my skills on google sheets to analysis and sort data to create a dashboard:

Throughout this process I have learnt how to extract key information from raw pieces of data to ultimately create a collected and well-organised visual representation of the data I have explored overall. The most important things I've learnt are how to use slicers, pivot tables and new functions on google sheets, helping me tremendously improve my dashboard. Slicers allowed me to filter out results making a more interactive dashboard experience for the user. And pivot tables helped me collect information with my format by using tools such as Values, Filters and Row buttons that served very helpful once I learned how to use them. Altogether, these skills have significantly strengthened both the quality and usability of my dashboard.
