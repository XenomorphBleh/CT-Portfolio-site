this site - personal reflection

This portfolio website is my first piece of code, made by my small accumulation of knowledge in the vast world of HTML and CSS code. Creating my first portfolio website was definitely a challenging but rewarding experience, helping me develop both my technical skills and my design thinking. At the start of the project, my main focus was simply getting the structure of the site working using HTML. However, as I progressed, I began to think more about layout, visual style, and how users would be able to interact with my content, which I found very interesting as I began to research how to make my site more interactive.

One of the most important features I worked on was the “bubble” design used to display my projects. Initially, I placed the bubbles in a simple, structured layout, but this was not the look I had been expecting, the design was too rigid and straight which was not what I wanted to achieve. To fix this, I experimented with manually adjusting margins using different classes (such as .one, .two, .three etc.) to shift each bubble left or right. Although this approach was not the most efficient, it allowed me to create a more scattered layout, which better reflected the style I wanted in my site. This process taught me how positioning and spacing can significantly impact the overall user experience, I also learned how to make one div split further so each bubble could have its own code (in positioning).

Another key feature I developed was the hover effect on the bubbles. Using CSS transitions and transforms, I made the bubbles shrink slightly when hovered over. This small interaction made the site feel more dynamic. While working on this, I had to experiment with transition timing and transform properties to make the animation feel smooth rather than abrupt. This helped me understand how CSS can be used not just for styling, but also for adding interactivity. I look to add more of these features in my work as I find more properties for transitions and small animations in my site!

Another CSS feature I used was background images, gradients, and masking. For example, I used radial gradient masks in sections like .projects and .top to create a fading visual effect. Although I was able to implement backgrounds, I was not fully satisfied with the images I chose :[, they did not completely merge into each other (to keep the website flowing), instead it was a sharp line between the top and projects section. In the future, I would like to design or find a more suitable background that better complements the bubble aesthetic.

I have later realised that my flex box on the bubbles (on the first page) is unresponsive for different screen sizes, thus becoming a problem for future me to solve!

Throughout the project, I used Visual Studio Code for coding and organised my files across multiple pages.

Ultimately, I would like to improve my site by making it more responsive instead of relying on fixed margins, and by adding more interactive elements using JavaScript?? Overall, this project let me experiment with code, developed my problem-solving (spending way too long finding bugs), and turning my ideas into a working website! I enjoyed the process of making this site and I’m ready to make more/add on to this draft piece.
